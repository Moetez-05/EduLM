\# EduLM



EduLM is an AI-powered study and exam assistant designed to help students learn from their own educational documents.



\## Technologies



\- React Native

\- TypeScript

\- Python

\- FastAPI

\- PyTorch

\- Firebase

\- RAG

\- Transformer / LLM



\## Main Features



\- User authentication

\- PDF import

\- Document analysis

\- AI question answering

\- Summarization

\- Quiz generation

\- Exercise generation

\- Exam analysis

\- Personalized learning

\- Revision planning
